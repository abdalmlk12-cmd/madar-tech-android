MADAR TECH – مدار تك | مشروع تطبيق Android

مشروع أولي لتطبيق الزبائن بواجهة عربية RTL وألوان مدار تك.
يتضمن كتالوج المنتجات والتصنيفات والبحث، صفحات الخدمات وطلب الخدمة، الاتصال والبريد وفتح واتساب.

البناء:
- يمكن فتح المشروع في Android Studio ثم تنفيذ Build > Build APK(s).
- أو استخدام ملف BUILD_APK_FROM_PHONE_AR.txt لاستخراج نسخة تجريبية من الهاتف عبر GitHub Actions.

حدود الإصدار الحالي:
- الكتالوج محلي داخل التطبيق، ولا توجد قاعدة بيانات مشتركة أو لوحة إدارة متصلة بالموقع.
- الصور الحالية رسومات توضيحية وليست صوراً رسمية أصلية للموديلات.
- طلبات الزبائن تفتح رسالة واتساب ليقوم الزبون بمراجعتها وإرسالها.
- ملف APK الناتج من GitHub Actions هو Debug APK للتجربة، وليس إصدار متجر نهائياً.
